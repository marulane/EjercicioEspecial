Ejercicio Especial para Evaluación


En este ejercicio se hace una llamada a una API para cargar datos (imágen, título, descripción y precio) de productos a 9 cards previamente definidas en el HTML. Se hace uso de promesas para recuperar la información y se manipula el DOM de la pagina con los datos recuperados del JSON. Finalmente se crea un eventListener al botón de Load Products para ejecutar esta función.
